Wie erstelle ich ein Token?

1. Auf github.com: oben rechts Profilbild → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
2. Repository access: nur dieses eine Repo auswählen.
3. Permissions → Contents: Read and write.
4. Token erstellen, kopieren und hier oben einfügen.
